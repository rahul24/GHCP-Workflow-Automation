# Follow the Instructions

1. Get the latest active PRs from Software RP. 
2. Check the `PR-Tracker.md` exists in the docs folder if not create it (Refer PR-Tracker.md structure). 
3. Compare with output if any new PR available then include in the markdown file.
4. Classify each PR by its content i.e. Code review, Design Review. Include the Classification in `PR Classification` column of `PR-Tracker.md`. 
5. Update the `PR Status` column in `PR-Tracker.md` if PR status got changed.
6. Remove the 3 month old PRs from `PR-Tracker.md`.
